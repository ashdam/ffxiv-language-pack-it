# Language pack in italiano per FFXIV (non ufficiale)

Traduzione italiana dei testi di Final Fantasy XIV per il plugin di Dalamud
**Gubal Library**. Non modifica i file originali del gioco.

Installazione e stato della traduzione:
**[eorzealocalized.com/it/](https://eorzealocalized.com/it/)**

Come collaborare alla traduzione, passo per passo:
**[eorzealocalized.com/localize/it.html](https://eorzealocalized.com/localize/it.html)**

Una riga tradotta male: https://github.com/ashdam/ffxiv-language-pack-it/issues
